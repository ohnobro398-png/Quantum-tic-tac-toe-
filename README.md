# Quantum Tic-Tac-Toe

A single-page tic-tac-toe game with a twist: quantum moves.

## How to play

1. Open `Index.html` in a browser.
2. Take turns placing X and O.
3. Use the quantum-mode button to try quantum moves (the page explains the rules).
4. The first player to complete a line wins; a full board with no line is a draw.
