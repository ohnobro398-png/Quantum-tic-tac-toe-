# Security Policy — Quantum Tic-Tac-Toe

## Scope

This policy covers this repository only. This is a static browser game (a single HTML page) with no backend, no accounts, and no data collection.

## Reporting a vulnerability

Open a GitHub Issue in this repository describing the issue **without** including exploit details or a working exploit.

## Out of scope

- Third-party code loaded by the page (fonts, the confetti library) comes from public CDNs; issues in those libraries belong to their own projects.
